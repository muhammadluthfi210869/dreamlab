## Search Journey Architecture Framework

Sebelum optimasi, kita harus paham:

`
User Search Journey untuk Maklon Kosmetik:

Awareness (Informational)
  ├── "cara membuat produk skincare"
  ├── "bahan aktif untuk kosmetik"
  └── "tren kosmetik 2025"

Consideration (Commercial Investigation) ← INI HIGHEST VALUE
  ├── "biaya maklon kosmetik"
  ├── "maklon skincare MOQ kecil"
  ├── "jasa maklon BPOM"
  └── "pabrik kosmetik sidoarjo"

Decision (Transactional)
  ├── "maklon kosmetik dreamlab"
  ├── "konsultasi maklon gratis"
  └── "wa dreamlab"

Post-Purchase
  ├── "proses maklon berapa lama"
  └── "cara urus BPOM setelah produksi"
`

**Implikasi:**
- Setiap artikel harus punya *search journey position*
- CTA harus sesuai dengan posisi itu
- Commercial Investigation articles → decision block + lead capture
- Informational articles → authority building + assisted conversion
- Jangan paksa "Konsultasi Gratis" di artikel informational

## SERP Analysis Protocol (WAJIB sebelum rewrite)

`
STEP 1: Cari keyword utama artikel
STEP 2: Google → lihat 10 besar SERP
STEP 3: Catat page types (blog? product? category? landing?)
STEP 4: Catat common sections (harga? FAQ? review? tutorial?)
STEP 5: Identifikasi missing angles (apa yang tidak dimiliki kompetitor?)
STEP 6: Differentiation (kenapa halaman Dreamlab harus menang?)
STEP 7: Baru rewrite outline
`

## Conversion Architecture per Intent

### Commercial Investigation (Phase 1-2)

`
Struktur artikel:
  1. Problem (mengapa pembaca ada di sini)
  2. Solution overview (maklon sebagai solusi)
  3. Decision block ⭐⭐⭐
     - Tabel perbandingan
     - Estimasi biaya
     - Timeline
     - Checklist
  4. Evidence (sertifikasi, klien, hasil)
  5. FAQ (answer decision uncertainty)
  6. CTA ⭐⭐⭐
     - BUKAN "Konsultasi gratis"
     - TAPI "Diskusikan kebutuhan [spesifik] Anda"
     - Lebih qualified, lebih tinggi konversi
`

### Informational (Phase 3-4)

`
Struktur artikel:
  1. What (definisi)
  2. Why (manfaat/mekanisme)
  3. How (aplikasi, formulasi, bisnis)
  4. Evidence (data ilmiah untuk YMYL)
  5. Assisted CTA ⭐⭐⭐
     - "Pelajari ingredient lain untuk formulasi [produk]"
     - "Lihat produk [kategori] yang bisa diproduksi"
     - BUKAN langsung "Konsultasi gratis"
`

## Quality Gates & E-E-A-T

### Claim Validation

Sebelum publish, setiap claim harus diverifikasi:

| Claim | Contoh | Verifikasi |
|-------|--------|------------|
| "Modal kecil" | Berapa? 5 juta? 10 juta? | **WAJIB ada angka riil** |
| "Laris" | Bukti apa? | **WAJIB ada data atau testimoni** |
| "BPOM" | Sudah terdaftar? | **WAJIB link ke sertifikat** |
| "Grade A" | CPKB? | **WAJIB link ke sertifikat** |

### YMYL Compliance (Topik Kosmetik)

Kosmetik = YMYL (Your Money or Your Life). Konsekuensi:
- ✅ Klaim bahan aktif harus punya sumber ilmiah
- ✅ Klaim manfaat harus sesuai regulasi BPOM
- ✅ Dilarang klaim medis ("menyembuhkan", "mengobati")
- ✅ Penulis artikel harus terverifikasi (author bio)
- ✅ Tanggal publikasi dan update harus jelas

### Thin Content Safeguard

Bukan tentang word count, tapi tentang:
- ✅ Apakah artikel menjawab query sepenuhnya?
- ✅ Apakah ada informasi yang tidak dimiliki kompetitor?
- ✅ Apakah artikel punya nilai standalone (tidak butuh artikel lain untuk dipahami)?
- ✅ Apakah decision uncertainty terjawab?

### Rules

1. **Jangan gunakan anchor yang sama untuk 2 halaman berbeda** → membingungkan entity understanding
2. **Anchor harus deskriptif** → bukan "klik di sini" atau "baca selengkapnya"
3. **Link dari halaman authority ke halaman yang butuh authority** → distribute PageRank
4. **Setiap halaman harus punya ≥2 incoming link** → tidak boleh orphan
5. **Setiap cluster harus link ke pillarnya** → reinforce topical hierarchy

## Layer 6: SERP Feature Intelligence

### Sebelum Rewrite, Cek SERP Features untuk Keyword Utama

```
SERP FEATURE CHECKLIST:

[ ] Featured Snippet?
     → Ya: format konten dengan list/table/paragraph yang bisa diambil Google
     → Tidak: cek apakah ada peluang mendapatkannya

[ ] People Also Ask?
     → Ya: jawab pertanyaan tersebut di artikel (FAQ section)
     → Tidak: tetap tambah FAQ untuk long-tail capture

[ ] AI Overview (SGE)?
     → Ya: pastikan konten mudah diekstrak AI (structured, clear answers)
     → Tidak: tetap optimasi untuk AI readiness (SEO fundamentals)

[ ] Local Pack?
     → Ya: pastikan NAP konsisten, GBP terisi (untuk local pages)
     → Tidak: tidak relevan untuk non-local pages

[ ] Video (YouTube/Shorts)?
     → Ya: embed relevant video, transkrip
     → Tidak: tidak perlu

[ ] Gambar?
     → Ya: optimize alt text, file name, caption
     → Tidak: tambah gambar relevan untuk visual search

[ ] Shopping?
     → Ya: product schema + pricing
     → Tidak: hanya untuk produk
```

### Contoh Penerapan untuk #19 "Jasa Maklon Kosmetik BPOM"

| SERP Feature | Ada? | Rekomendasi |
|:------------:|:----:|-------------|

| PAA | Cek | Tambah 5-8 FAQ di artikel |
| AI Overview | Cek | Pastikan ada definisi/jawaban eksplisit di paragraf awal |
| Local Pack | Mungkin | Untuk varian "pabrik kosmetik surabaya" → beda halaman |
| Video | Cek market | Jika kompetitor punya → embed virtual tour pabrik |

> **Keterbatasan:** SERP feature analysis membutuhkan akses langsung ke Google SERP untuk setiap keyword. Tim konten harus melakukan ini manual sebelum rewrite.
