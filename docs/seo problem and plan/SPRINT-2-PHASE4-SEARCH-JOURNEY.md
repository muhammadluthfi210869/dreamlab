## Executive Summary

### The Problem

Dreamlab has 456 pages, strong technical SEO, and a content advantage over competitors. But the website is designed as a **catalog** — not as a **customer acquisition system**. There is no deliberate journey from anonymous searcher to qualified lead. Pages exist in isolation. CTAs are inconsistent. There are no lead magnets, no pricing pages, no case studies, no structured conversion path.

### The Solution

Design the **complete organic customer acquisition journey** — a deliberate, psychology-driven path that transforms a stranger's Google search into a predictable, qualified Dreamlab lead.

### Core Insight

In B2B manufacturing (maklon kosmetik), the buyer's journey follows a **predictable 5-stage pattern**:

```
"Aku mau buat brand kosmetik" 
    → "Bagaimana caranya?" 
    → "Berapa biayanya?" 
    → "Siapa yang terpercaya?" 
    → "Saya mau konsultasi"
```

Each stage has specific questions, objections, and information needs. Dreamlab's current website answers almost **none of these questions directly**. The gap is not in pages — it's in **journey design**.

### The Highest-Value Journey

**If Dreamlab could build only ONE customer journey, it should be:**

> **The First-Time Beauty Entrepreneur Journey**
> (Targeting: "Aku mau buat brand kosmetik tapi belum tahu caranya")

**Why this journey?**
1. Largest addressable audience (thousands of new beauty entrepreneurs monthly)
2. Longest potential lifetime value (first brand → expansion → multiple products)
3. Lowest competition (no competitor targets this journey explicitly)
4. Highest conversion potential (help them from zero → Dreamlab client)
5. Natural advocacy (successful first brand owners refer others)

**Estimated impact:** 10-15 qualified leads/month from this journey alone within 90 days.

**Confidence:** High (8/10)

### Buyer Psychology — Common Threads

Across all personas, these psychological drivers are universal:

| Driver | Explanation | Application for Dreamlab |
|--------|------------|------------------------|
| **Loss aversion** | "I don't want to waste money on bad products" | Offer sample production, money-back guarantee on formulation |
| **Social proof** | "If others succeeded, I can too" | Feature brand logos prominently, case studies, testimonials |
| **Authority bias** | "Certified = trustworthy" | Show BPOM, Halal, CPKB logos everywhere |
| **Ambiguity aversion** | "I don't understand the process = risky" | Explain every step clearly; transparency reduces perceived risk |
| **Anchoring** | "First price I see becomes my reference" | Show pricing early to anchor expectations |
| **Status quo bias** | "It's easier to do nothing" | Make first step (consultation) as easy as possible |
| **Reciprocity** | "You helped me = I want to work with you" | Provide free value (guides, consultations) before asking for commitment |

## Search Intent Evolution

### The 5-Stage Mental Model

A potential client does NOT search "maklon kosmetik" first.

They start with a **dream**, then a **problem**, then a **search**.

```
Stage 1: DREAM
"I want to build a beauty brand"
→ Searches: "cara buat brand kosmetik", "bisnis kosmetik modal kecil"

Stage 2: EXPLORE
"What does it take to make products?"
→ Searches: "maklon itu apa", "cara maklon kosmetik", "private label artinya"

Stage 3: EVALUATE
"How much does it cost? Who can I trust?"
→ Searches: "biaya maklon skincare", "moq maklon", "pabrik maklon terpercaya"

Stage 4: COMPARE
"Which manufacturer is best for me?"
→ Searches: "maklon kosmetik terbaik", "rekomendasi pabrik maklon", "[brand] vs [brand]"

Stage 5: ACT
"I'm ready. Who do I contact?"
→ Searches: "maklon kosmetik surabaya", "konsultasi maklon", "kontak pabrik maklon"
```

### Critical Leakage Points

**Leakage #1: The Pricing Wall**
- User lands on homepage → sees "Konsultasi Gratis" → doesn't know cost → hesitant to contact → leaves
- **Fix:** Create pricing page that gives enough info to self-qualify, then prompts consultation

**Leakage #2: The Trust Gap**
- User reads about Dreamlab → no case studies → no portfolio → "Can I trust them?" → leaves
- **Fix:** Case studies + client logos + portfolio gallery

**Leakage #3: The No-Follow-Up**
- User fills form or WhatsApp → no immediate response → loses interest → goes to competitor
- **Fix:** Automated WhatsApp response + same-day human follow-up

**Leakage #4: The Missing Micro-Conversion**
- User reads blog article → no CTA → leaves → never returns
- **Fix:** Every piece of content has a CTA (download, pricing, consultation)
