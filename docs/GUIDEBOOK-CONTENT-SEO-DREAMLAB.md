## 2. Pemetaan Funnel B2B & Profil Audience (Tier 1, 2, 3)

Dalam industri maklon kosmetik, calon klien memiliki tingkat kesiapan modal dan pengetahuan teknis yang sangat berbeda. Penulisan artikel harus menyesuaikan *tone of voice* dan *pain point* target audience:

```
[ TOF: AWARENESS / INFORMATIONAL ] ──► Belum tahu teknis maklon, riset tren bahan & peluang
[ MOF: CONSIDERATION / COMMERCIAL ] ──► Mulai memilih pabrik, membandingkan formula, cek legalitas
[ BOF: CONVERSION / TRANSACTIONAL ] ──► Siap modal, cek simulasi HPP, sistem pembayaran, kontak sales
```

### Karakteristik 3 Tier Audience Dreamlab:

#### A. Tier 1: Pemula / Reseller / KOL & Influencer
- **Ciri**: Belum pernah memiliki brand sendiri, modal awal terbatas (Rp 20–50 Juta), takut tertipu biaya tersembunyi, awam alur legalitas BPOM.
- **Pain Point Utama**: *"Bisa nggak maklon modal kecil? Takut produk nggak laku atau tertahan di BPOM."*
- **Pendekatan Konten**: Bimbingan langkah demi langkah, simulasi modal transparan, penegasan bahwa Dreamlab mendampingi legalitas hingga izin edar terbit.

#### B. Tier 2: Brand Owner UMKM / Beautypreneur Scale-Up
- **Ciri**: Sudah memiliki brand berjalan, butuh inovasi produk baru, butuh variasi SKU (serum, body lotion, sunscreen), butuh kepastian HPP untuk margin iklan.
- **Pain Point Utama**: *"Formula pabrik lama pasaran, minimum order terlalu besar, pengiriman sering molor."*
- **Pendekatan Konten**: Diferensiasi formula R&D eksklusif (*1 Client 1 Formula*), komparasi performa bahan aktif, efisiensi HPP agar profit margin sehat saat pasang iklan TikTok/Meta Ads.

#### C. Tier 3: Dokter SpKK, Klinik Estetika & Korporat
- **Ciri**: Reputasi medis dipertaruhkan, butuh standar sterilisasi tinggi, volume pesanan besar dan berkelanjutan.
- **Pain Point Utama**: *"Apakah pabrik benar-benar Grade A? Apakah formula aman untuk kulit sensitif/pasca tindakan medis?"*
- **Pendekatan Konten**: Penegasan fasilitas CPKB Grade A mandiri di Jawa Timur, bahan baku bersertifikat global (COA terverifikasi), formulasi *hypoallergenic* bebas alkohol/paraben.

- **Target Audience**: Tier 1 (Pemula skincare modal 20–50 jt), Tier 2 (Brand skincare lokal scale-up), Tier 3 (Dokter SpKK & Klinik Estetika).

## 5. Standar Penulisan & Format Artikel (Zero-Error Checklist)

Mengacu langsung pada peraturan mutlak **STANDAR-ARTIKEL-DREAMLAB.md**:

### A. Larangan Keras (Negative Constraints)
1. ❌ **0 Emoji**: DILARANG KERAS menggunakan emoji apa pun di dalam H1, H2, H3, paragraf, daftar isi, tabel, maupun tombol CTA.
2. ❌ **Anti-Sesak Mobile**: Dilarang membuat tabel horizontal dengan lebih dari 3 kolom yang membuat tampilan mobile gepeng/rusak.
3. ❌ **Dilarang Menampilkan Nomor Kantor (0881...)**: Seluruh kontak hanya boleh mengarah ke WhatsApp Sales aktif atau halaman `/thankyou/google/`.
4. ❌ **Dilarang Skip Re-generate Meta**: Setiap update `src/data/articles.ts` WAJIB menjalankan generator metadata blog.

### B. Struktur HTML Wajib
1. **Container Utama**:
   ```html
   <div class="elementor-element elementor-element-4cdeffb8 elementor-widget elementor-widget-theme-post-content">
     <!-- Konten Artikel -->
   </div>
   ```
2. **Paragraf Pembuka**: Edukasi latar belakang masalah, hook emosional pembaca.
3. **Table of Contents (ToC)**:
   ```html
   <nav style="background:#f9f8f6;border:1px solid #e5e0d8;border-radius:12px;padding:24px 28px;margin:32px 0;">
     <p style="font-weight:700;font-size:18px;margin-bottom:12px;color:#1a202c;">Daftar Isi Artikel</p>
     <ol style="margin:0;padding-left:20px;line-height:1.8;color:#4a6fa5;">
       <li><a href="#section-1" style="color:#4a6fa5;text-decoration:none;">Sub-judul 1</a></li>
     </ol>
   </nav>
   ```
4. **Gambar Tengah (Wajib Link ke `/thankyou/google/`)**:
   ```html
   <figure style="margin:36px 0;text-align:center;">
     <a href="https://dreamlab.id/thankyou/google/" target="_blank" rel="noopener">
       <img class="bv-tag-attr-replace bv-lazyload-tag-img" 
            bv-data-src="/assets/images/blog/dreamlab_maklonkosmetik_artikel_tengah.png" 
            alt="Konsultasi Maklon Kosmetik Dreamlab Indonesia" 
            style="width:auto;height:auto;max-width:100%;border-radius:12px;" />
     </a>
   </figure>
   ```
5. **Bagian Inti (H2, H3, Card Deskripsi / Tabel Responsif)**: Setiap H2 wajib memiliki atribut `id` yang cocok dengan ToC.
6. **Gambar Bawah (Wajib Link ke `/thankyou/google/`)**:
   ```html
   <figure style="margin:36px 0;text-align:center;">
     <a href="https://dreamlab.id/thankyou/google/" target="_blank" rel="noopener">
       <img class="bv-tag-attr-replace bv-lazyload-tag-img" 
            bv-data-src="/assets/images/blog/dreamlab_maklonkosmetik_artikel_akhir.png" 
            alt="Mulai Brand Kosmetik Sendiri Bersama Dreamlab" 
            style="width:auto;height:auto;max-width:100%;border-radius:12px;" />
     </a>
   </figure>
   ```
7. **Tombol Call to Action (CTA)**:
   ```html
   <div style="text-align:center;margin:48px 0;padding:36px;background:#fcfbf9;border:1px solid #efebe4;border-radius:16px;">
     <h3 style="font-size:22px;font-weight:700;color:#1a202c;margin-bottom:12px;">Wujudkan Brand Kosmetik Impian Anda Sekarang</h3>
     <p style="color:#4a5568;max-width:600px;margin:0 auto 24px;line-height:1.6;">Diskusikan ide produk, estimasi modal, dan sampel formula gratis bersama tim R&D Dreamlab.</p>
     <a href="https://dreamlab.id/thankyou/google/" target="_blank" rel="noopener" 
        style="display:inline-block;background:#D98A00;color:#ffffff;font-size:16px;font-weight:800;padding:16px 36px;border-radius:50px;text-decoration:none;box-shadow:0 4px 14px rgba(217,138,0,0.35);">
       Konsultasi Gratis dengan Dreamlab
     </a>
   ```

8. **FAQ Accordion Schema**: Minimal 3 pertanyaan yang sering diajukan pembaca menggunakan tag `<details>` dan `<summary>`.

### C. Aturan Link Internal & Eksternal
- **Internal Link**: Minimal 4 tautan ke halaman produk terkait atau artikel pendukung di domain `dreamlab.id`.
- **External Link**: Minimal 2 tautan otoritatif berkredibilitas tinggi (BPOM, Kemenperin, PubMed) dengan atribut `rel="nofollow" target="_blank"`.

## 7. Prosedur Deployment & Validasi Sistem

Setiap kali batch artikel selesai ditulis di `src/data/articles.ts`, jalankan rangkaian perintah wajib berikut di terminal:

```bash
# Langkah 1: Generate metadata ringkas artikel untuk blog archive (/news-blog)
node scripts/gen-articles-meta.mjs

# Langkah 2: Sinkronisasi path routing dan dimensi gambar
npm run gen:paths
node scripts/gen-image-dims.mjs

# Langkah 3: Verifikasi kepatuhan SEO dan schema
npm run verify:seo

# Langkah 4: Uji kompilasi build Next.js (wajib 0 error)
npx next build

# Langkah 5: Git commit & deploy ke Vercel production
git add -A
git commit -m "feat(seo): publish batch artikel baru"
git push origin master
vercel --prod --yes
```
